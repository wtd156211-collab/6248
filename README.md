# turnwise：带转向限制的最短路径（从 0 实现）

仓库里只有本说明、`samples/**` 和 `.gitignore`；求解器与页面都要从零新写。

## 1. 范围

交付两个新文件，都放在仓库根目录：

- `solve.py`：命令行求解器。`python solve.py <查询文件>` 读入一个查询文件，把结果 JSON 写到 stdout，只用 Python 3.13 标准库。
- `index.html`：单文件页面。路网与查询数据内联在文件里，双击（`file://`）即可打开，不起服务、不发网络请求。

要支持两种查询：两点最小代价路径（`path`）、单源多目标代价表（`table`）。

不做：路网编辑/保存/导入导出；后端服务与多用户；负代价、小数代价、时间窗、通行费；转向惩罚（转向只有「允许 / 禁止」两态）；真实地理投影与底图，节点坐标只用于画示意图；第三方依赖、构建步骤、联网。`index.html` 直接以交付物形式放在仓库里，运行 `solve.py` 时除 stdout 外不写任何文件。

## 2. 口径与公式

- 路径是**有向边序列** `p = [e1, …, ek]`（k ≥ 0）。合法路径：`from(e1) = 起点`，`to(ei) = from(ei+1)`，`to(ek) = 终点`。
- 代价 `C(p) = Σ cost(ei)`，`cost` 为正整数；空路径（起点 = 终点）代价 0，合法。
- 转向限制按（入边，出边）描述：相邻对 `(ei, ei+1)` 一旦命中限制表，整条路径即不合法。单边路径与空路径没有转向，不受限制表影响。
- **选路规则**：先在合法路径中取代价最小者；代价并列时比较边 id 序列，从左往右逐项按字符串比大小（等价于 Python 的 `<`），第一处不同处小者胜；一方是另一方前缀时短者胜。
- 没有合法路径时 `cost = null`、`path = []`。

## 3. 状态与转移

- 状态取「刚驶入的那条边」，不取节点：禁转作用在相邻两条边的接缝上，只记节点会丢掉「从哪条边进来」的信息。
- 后继 `succ(e) = { f : from(f) = to(e) 且 (e, f) 不在限制表 }`；起点的初始状态是全部 `from(e) = 起点` 的边，`to(e) = 终点` 的状态是收尾状态。
- 节点可以没有出边；同一条边在搜索中可以反复经过；搜索算法自选，结果必须与第 2 节一致。

## 4. 输入、输出与文件格式

全部为 UTF-8 JSON，数值字段写数字不写字符串。

### 4.1 路网 `samples/networks/*.json`

下面是字段片段（不是 `samples/` 里的真实文件）：

```json
{"id": "demo",
 "nodes": [{"id": "S", "x": 0, "y": 0}, {"id": "A", "x": 4, "y": 0}, {"id": "B", "x": 0, "y": 4}],
 "edges": [{"id": "S-A", "from": "S", "to": "A", "cost": 3},
           {"id": "A-B", "from": "A", "to": "B", "cost": 2},
           {"id": "S-B", "from": "S", "to": "B", "cost": 9}],
 "turn_restrictions": [{"in": "S-A", "out": "A-B"}]}
```

- `nodes[].id`、`edges[].id` 各自唯一；`x`/`y` 为示意坐标，x 向右、y 向下。
- `edges[].from` / `to` 必须是已声明的节点；`cost` 为 1…10^6 的整数；同一对节点之间允许多条平行边。
- `turn_restrictions[].in` / `out` 必须是已声明的边且 `to(in) = from(out)`，表示「从 in 驶入后随即驶出 out」被禁；表内不重复。

### 4.2 查询 `samples/queries/*.json`

```json
{"network": "samples/networks/demo.json",
 "queries": [{"id": "q1", "type": "path", "from": "S", "to": "B"},
             {"id": "q2", "type": "table", "from": "S", "targets": ["A", "B"]}]}
```

`network` 是相对仓库根目录的路径；`queries[].id` 在文件内唯一；`type` 取 `path`（带 `from` / `to`）或 `table`（带 `from` 与有序不重复的 `targets`）。查询里出现的节点必须在路网中声明过。

### 4.3 结果与预期文件

stdout 是一个 JSON 数组，顺序与查询一致：

```json
[{"query_id": "q1", "type": "path", "from": "S", "to": "B", "cost": 9, "path": ["S-B"]},
 {"query_id": "q2", "type": "table", "from": "S", "rows": [
    {"to": "A", "cost": 3, "path": ["S-A"]},
    {"to": "B", "cost": 9, "path": ["S-B"]}]}]
```

上例里 `S-A` → `A-B` 被禁，S→B 只能走代价 9 的 `S-B`。路径用边 id 序列表示；`table` 按 `targets` 顺序逐行给出。stdout 只放这一个 JSON，诊断信息走 stderr。`samples/expected/<同名>.json` 就是对应查询文件应当得到的输出，可逐行核对。

### 4.4 页面 `index.html`

- 单文件、数据内联，`file://` 双击打开即用；不读取本地文件、不起服务、不联网。
- 页面上要能看到：路网示意图（节点、带方向的边、路口处的禁转标记）、所选查询的路径高亮与总代价，以及两类转向限制条目：
  - **被避开的转向限制**：忽略限制时的最省路线会踩到、而合法解已经绕开的条目（红色），同时列出那条违章路线和它的代价，便于对照；
  - **未被绕开的转向限制**：限制表里这次查询用不到的其余条目（灰色，注明与本查询无关）。
- 页面展示的代价与路径必须与 4.3 的预期一致，至少覆盖 `samples/` 的 4 组路网与全部查询。

## 5. 性能与验收口径

规模上限：单组路网节点 ≤ 2000、有向边 ≤ 20000、转向限制 ≤ 20000；单个查询文件 ≤ 200 条查询；单条 `table` 的 targets ≤ 2000。

耗时预算（冷启动，含读文件与输出）：规模取上限时单条查询 ≤ 1 秒；`samples/queries/` 全部跑完 ≤ 10 秒；页面打开到首次渲染 ≤ 3 秒。

验收：

1. 对每个 `samples/queries/*.json`，`python solve.py <该文件>` 的 stdout 与 `samples/expected/` 下同名文件结构等价（忽略空白与键顺序）。
2. 输出路径逐条合法（首尾衔接、不命中禁转），代价等于路径上边代价之和；不存在更小代价的合法路径；并列时按第 2 节规则取到唯一一条。
3. 规模与耗时不超过上面的预算；只使用 Python 3.13 标准库，不改动机器上的全局配置。
4. `index.html` 双击可开、无网络请求，且体现 4.4 列出的全部信息。

## 6. 样例说明

4 组路网、17 条查询。查询文件在 `samples/queries/`，预期文件在 `samples/expected/`，两者同名一一对应：

| 路网 | 覆盖的场景 | 文件名 |
| --- | --- | --- |
| `n1_cycle` | 单向回路：只能顺着环走；起点等于终点得空路径（代价 0） | `n1_cycle.json` |
| `n2_parallel` | 多平行边：最便宜的边被两条禁转堵死，只能改走另一条平行边（忽略限制 6，合法 8） | `n2_parallel.json` |
| `n3_isolated` | 孤立节点与不可达（`cost = null`）；两条同代价路线按边 id 取小者 | `n3_isolated.json` |
| `n4_detour` | 禁左强制绕行（S→B 由 4 变 8）；另有两处与查询无关的禁转；S→D 的违章直连与合法路线同代价 | `n4_detour.json` |

`samples/notes.md` 是现场记录：现在的做法先按节点算最短路、事后才看禁转，n4 上给出了违章路线。
